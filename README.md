# 🧠 Brain Tumor Detection

A Machine Learning and Deep Learning project for classifying brain MRI images into four categories.

## 🎯 Objectives

The system classifies brain MRI images into:

- Glioma
- Meningioma
- Pituitary Tumor
- No Tumor

## 🧠 Approaches

Two approaches were explored:

### Machine Learning

A **Random Forest** classifier was used for image classification.

### Deep Learning

A **Convolutional Neural Network (CNN)** was developed to learn visual features directly from MRI images.

## 🔬 Workflow

1. Load the MRI image dataset.
2. Preprocess the images.
3. Organize the data into four classes.
4. Train Machine Learning and Deep Learning models.
5. Evaluate classification performance.
6. Predict the class of new MRI images.
